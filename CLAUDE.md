# Working on Cutgenie

## Commits and pull requests

- Never push to `main` directly. Make a branch, push it, and open a pull request; merge only after the owner approves it.
- Do not add `Co-Authored-By` lines or "Generated with Claude Code" lines to commits or pull requests.
- New releases must attach the disk image as `Cutgenie.dmg` (techzonical.com links to `releases/latest/download/Cutgenie.dmg`).
