# What's new

The full list is in [CHANGELOG.md](../../CHANGELOG.md). Highlights:

**Coming in the next version**

- Beginner documentation with screenshots for every chapter.
- Claude Code skills and plugin: edit by asking in plain words.
- New control command `set_zoom` for zooms on the main track.
- Fix: the `seek` control command now moves the playhead too.

**0.1.0, first public release**

- Magnetic timeline with any number of video, graphics and sound tracks.
- Transform, zoom and crop with keyframes and a graph editor.
- Colour correction, wheels, LUTs and saved looks.
- Text, shapes, blur areas, builds, behaviours and saved titles.
- Sound clean-up and loudness matching.
- Versions, autosave, crash recovery, relink and collect media.
- Export presets for YouTube, small files, masters and sound only.
