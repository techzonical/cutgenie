# Glossary

| Word | Meaning |
| --- | --- |
| **Adjustment layer** | An empty clip on an upper track; its colour and effects change everything below it. |
| **Append** | Add a clip at the end of the timeline (**E**). |
| **Blade** | Cut a clip in two at the playhead (**⌘B**, or the **B** tool). |
| **B-roll** | Extra shots placed over the main video, on V2 and above. |
| **Clip** | One piece of video, sound or picture on the timeline. |
| **Codec** | The way a video file is compressed, such as H.264, HEVC or ProRes. |
| **Colour correction** | Fixing brightness and colour so a shot looks natural. |
| **Colour grading** | Giving footage a style or mood with colour. |
| **Export** | Turning the project into one finished video file. |
| **Fade** | Sound or picture that starts or ends gently instead of suddenly. |
| **Frame rate (fps)** | How many pictures make one second of video, e.g. 30. |
| **Gap** | Empty space on the timeline; it plays as black and silence. |
| **Group** | Clips tied together so they select and move as one (**⌘G**). |
| **Insert** | Put a clip at the playhead and push later clips right (**W**). |
| **Inspector** | The column on the right with the Effects, Color and Audio tabs. |
| **Keyframe** | A value stored at one moment; two keyframes make a change over time. |
| **Lift** | Remove a clip and leave a gap (**⇧⌫**). |
| **Linked sound** | A video clip's own sound, which moves with it. **⌘L** unlinks it. |
| **Log footage** | Flat, grey-looking video from some cameras; it needs an input LUT. |
| **Lower third** | A name or caption in the lower part of the frame. |
| **LUFS** | The unit for loudness. YouTube plays videos at about −14 LUFS. |
| **LUT** | A `.cube` file holding a ready-made colour change. |
| **Magnetic timeline** | The main track closes gaps by itself when you delete or move clips. |
| **Marker** | A named point on the timeline to find a moment again (**M**). |
| **Media** | Your original video, sound and picture files. Cutgenie never changes them. |
| **Picture in picture** | A small video on top of the main one. |
| **Playhead** | The line that shows which moment the viewer is showing. |
| **Project** | Your edit, saved as one small `.cutgenie.json` file. |
| **Relink** | Point the project at media files that were moved or renamed. |
| **Ripple delete** | Remove a clip and close the gap (**⌫**). |
| **Roll** | Move the cut between two clips, keeping the total length. |
| **Skimming** | Previewing by pointing at the timeline, without clicking (**S**). |
| **Slip** | Show a different part of a clip's media without moving it. |
| **Snapping** | Clips jump to edges and the playhead when close (**N**). |
| **Timeline** | The strip at the bottom where you arrange clips in time. |
| **Track** | One row of the timeline: V1, V2… for picture, A1, A2… for sound. |
| **Trim** | Make a clip shorter or longer from its start or end. |
| **Version** | An earlier save of the project; Cutgenie keeps the last 10. |
| **Viewer** | The big picture in the middle of the window. |
