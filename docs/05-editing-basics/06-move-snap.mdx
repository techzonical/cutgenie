# Move clips and snapping

- **Move**: drag a clip with the Select tool (**A**). On V1 the other clips make room.
- **Copy while moving**: hold **⌥** while you drag.
- **Nudge**: select a clip and press **,** or **.** to move it one frame; **⇧,** or **⇧.** for ten frames.
- **Move to another track**: drag it up or down.

**Snapping** (**N**) makes clips jump to the playhead, markers and other clips' edges when they're close, so things line up
exactly. Turn it off for fine positioning.

**Select several clips**
- **⌘-click** adds or removes one clip.
- **⇧-click** selects everything between two clips.
- Drag across empty space to draw a selection box.
- **⌘A** selects everything; **Esc** clears the selection.
