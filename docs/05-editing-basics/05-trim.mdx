# Trim the start or end of a clip

**Trimming** means making a clip start later or end earlier, to cut off the slow bits.

**Drag an edge**: point at the left or right edge of a clip on the timeline. The pointer changes. Drag in to shorten,
out to lengthen (as far as the recording goes).

**To the playhead** (precise)
1. Select the clip and put the playhead where it should start (or end).
2. Press **⌥[** to trim the start there, or **⌥]** to trim the end.

On the magnetic main track, later clips move to follow so no gap appears.

**The Trim tool (T)** changes where two clips meet: dragging the join makes one longer and the other shorter by the
same amount, so the total length stays the same. This is called a **roll**.
