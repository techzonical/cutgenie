# The magnetic main track

The main track, **V1**, is **magnetic**. Clips on it always sit next to each other with no empty gaps:

- Delete a clip and the ones after it slide left to close the hole.
- Drag a clip between two others and they move apart to make room.

This saves lots of tidying up, especially in talking-head videos.

Switch it off or on with the magnet button in the tool column, or **⌥P**. When it's off, clips stay exactly where
you put them, and deleting leaves a gap.

Tracks above V1 (V2, V3…) are never magnetic. Use them for things that must stay at a set time.
