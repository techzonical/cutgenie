# Install Cutgenie

Cutgenie comes as a **disk image**: a `.dmg` file that opens like a little USB stick on your Mac.

1. Go to the [Releases page](https://github.com/techzonical/cutgenie/releases) and download the newest
   `Cutgenie-<version>.dmg` (for example `Cutgenie-0.1.dmg`). It lands in your **Downloads** folder.
2. Double-click the `.dmg` file. A window opens with the Cutgenie icon and an **Applications** folder.
3. **Drag the Cutgenie icon onto the Applications folder.** This copies the app onto your Mac.
4. Close the window, then **eject** the disk image: in Finder's sidebar, click the ⏏ button next to *Cutgenie*.
5. You can now delete the `.dmg` file from Downloads. You don't need it any more.

> **Tip:** to keep Cutgenie in your Dock, open it once, then right-click its Dock icon and choose
> **Options ▸ Keep in Dock**.
