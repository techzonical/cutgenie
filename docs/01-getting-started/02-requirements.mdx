# What you need

- **A Mac with macOS 14 (Sonoma) or newer.** To check: click the Apple menu  in the top-left corner and choose
  **About This Mac**. The window shows your macOS name and number.
- **An Apple silicon Mac is best** (M1, M2, M3, M4 or newer). The same *About This Mac* window shows "Chip: Apple M…".
  Older Intel Macs may work, but editing will feel slower.
- **Free disk space** for your recordings and finished videos. Video files are big: one minute of 4K video can be
  several hundred megabytes, so keep tens of gigabytes free.

That's all. You don't need an account, a subscription or an internet connection to edit.

> **Building it yourself?** Only developers need this: Xcode command line tools and ffmpeg. See the main
> [README](../../README.md#build-and-run).
