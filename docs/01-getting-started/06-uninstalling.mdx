# Remove Cutgenie

1. Quit Cutgenie (**⌘Q**).
2. Open your **Applications** folder.
3. Drag **Cutgenie** to the **Bin** (Trash) in the Dock, then empty the Bin when you're ready.

That removes the app. **Your projects and video files are not deleted**: they stay wherever you saved them. Delete
those yourself only if you're sure you don't need them.

## Remove the settings too (optional)

Cutgenie keeps a few small settings, like your recent projects list. To remove them as well, open the
**Terminal** app and paste:

```bash
defaults delete com.techzonical.cutgenie
```
