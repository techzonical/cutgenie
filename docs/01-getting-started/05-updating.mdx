# Update to a new version

Your projects are saved in their own files, not inside the app, so updating never touches them.

1. In Cutgenie, choose **File ▸ Save** (or press **⌘S**), then quit with **Cutgenie ▸ Quit** (**⌘Q**).
2. Download the newest `.dmg` from the [Releases page](https://github.com/techzonical/cutgenie/releases).
3. Open it and drag **Cutgenie** onto **Applications** again.
4. When the Mac asks, click **Replace**.
5. Open Cutgenie. Your recent projects are still listed.

If macOS shows the security message again, follow
[step 2 of Open it for the first time](04-first-launch.mdx#2-if-macos-says-it-cant-check-the-app).

To see what changed in each version, read the [changelog](../../CHANGELOG.md).
