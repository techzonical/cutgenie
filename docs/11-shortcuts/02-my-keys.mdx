# Change a shortcut

1. Press **⌘/** to open the keyboard map.
2. Click **My keys…**.
3. Find the action and give it the key you want.
4. Click **Done**.

![The My keys… button is at the top of the keyboard map](../images/11-shortcuts/keyboard-map.png)
