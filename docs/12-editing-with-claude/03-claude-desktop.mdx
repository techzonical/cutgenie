# Use the Claude app instead of Claude Code

Don't use Claude Code? The regular **Claude app for Mac** can edit in Cutgenie too, with the **Cutgenie extension**.

1. Download **Cutgenie.mcpb** from the Cutgenie releases page on GitHub.
2. Open the Claude app, then double-click **Cutgenie.mcpb**. (Or open **Claude ▸ Settings ▸ Extensions** and drag the
   file in.)
3. Click **Install**. Leave the port at **7878** unless you changed it.
4. Open Cutgenie and the project you want to edit.
5. In a new chat, ask: *Can you see my Cutgenie?*

> ⚠️ **Don't attach your video or audio to the chat.** Just open your project in Cutgenie and ask in words, like
> *Add a title when I say my name.* The Cutgenie extension reads your files straight from your Mac.
>
> If you attach or upload a file, the Claude app copies it to Claude's online workspace, and Claude tries to work on
> that copy, where there is no Cutgenie and no Whisper. You then see messages like *"no speech-to-text model"* or
> *"package installs are blocked by your network settings"*. If that happens, start a new chat, attach nothing, and
> ask again.
>
> This is true for the regular Claude app chat and for Claude Code: both work without attaching anything.
> **Cowork** hasn't been tested yet and may have the same problem, because it also works in its own online workspace.

The first time Claude uses a Cutgenie tool, the Claude app asks for your permission. You can allow it once or always.

**What Claude can do with it**: everything in [The skills](05-skills.mdx): cut pauses, trim, add titles (placed by what you say), zoom, fix
sound and colour, blur, export, and check the edit. It can also show you a frame of the edited picture in the chat.

**The same safety rules**, built into the extension itself:

- it saves a version before the first edit,
- it never changes your original recordings,
- it never replaces an existing export unless you say yes,
- it can't close Cutgenie or delete your saved looks, titles or presets.

**Removing pauses** uses **ffmpeg**, and **placing things by what you say** uses **Whisper** (free, runs on your Mac;
see [Transcripts](08-transcripts.mdx)). If one isn't installed, Claude tells you and asks first. The Claude app can't install
programs itself, so you type the install command in Terminal (`brew install ffmpeg` or `brew install whisper-cpp`).

> While the Cutgenie code is private, the extension file is only available to people with access.
