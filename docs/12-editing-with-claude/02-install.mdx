# Install the Cutgenie skills

You need **Claude Code** and Cutgenie on the same Mac.

1. Open Claude Code.
2. Type this and press Return:

   ```text
   /plugin install cutgenie --marketplace techzonical/cutgenie
   ```

   On an older Claude Code, use two steps instead: `/plugin marketplace add techzonical/cutgenie`, then
   `/plugin install cutgenie@cutgenie`.

3. Open Cutgenie and the project you want to edit.
4. Ask Claude: *Can you see my Cutgenie?* Claude checks the connection and tells you which project is open.

> While the Cutgenie code is private on GitHub, the install only works for people who have been given access.

**Nothing else to install.** The skills talk to Cutgenie with `curl`, which every Mac already has. Some jobs use extra
free tools: removing pauses uses **ffmpeg**, and placing things by what you say
(see [Transcripts](08-transcripts.mdx)) uses **Whisper**, which turns speech into text on your Mac. Claude will ask before installing anything.
