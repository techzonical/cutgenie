# The skills

You don't need to name a skill. Just say what you want, and Claude picks the right one.

| Skill | What it does | Try saying |
| --- | --- | --- |
| **cutgenie-setup** | Checks the connection, opens or creates a project | *Can you see my Cutgenie?* |
| **cutgenie-projects** | Save, duplicate, vertical copy, versions, missing media | *Make a vertical copy for Shorts.* |
| **cutgenie-rough-cut** | Puts clips in order, removes silent pauses | *Cut the pauses out of my video.* |
| **cutgenie-trim** | Trims, splits, moves and speeds up clips | *Take 2 seconds off the end of clip 3.* |
| **cutgenie-titles** | Text, lower thirds, shapes, saved titles | *Add my name as a lower third at 0:05.* |
| **cutgenie-zoom-motion** | Zooms, punch-ins, picture in picture | *Slowly zoom in on the intro.* |
| **cutgenie-sound** | Volume, fades, music, voice clean-up, loudness | *Make it as loud as YouTube videos.* |
| **cutgenie-colour** | Brightness, colour, LUTs, saved looks | *Clip 4 is too dark and blue.* |
| **cutgenie-blur** | Blurs or pixelates faces, plates, private text | *Blur my phone number at 1:12.* |
| **cutgenie-export** | Exports for YouTube, small files, masters, sound | *Export it for YouTube.* |
| **cutgenie-review** | Checks the edit for problems before export | *Is it ready to export?* |
