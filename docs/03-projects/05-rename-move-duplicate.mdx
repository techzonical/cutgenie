# Rename, move or duplicate a project

Click the **project name** above the viewer to open the project menu.

| Menu item | What it does |
|---|---|
| **Rename…** | Gives the project a new name. |
| **Move to…** | Moves the project file to another folder. |
| **Save as…** | Saves a copy under a new name and keeps working in the copy. |
| **Duplicate…** | Makes a copy and stays in the original. Can also make a tall 9:16 copy for Shorts. |
| **Reveal in Finder** | Shows the project file in Finder. |
| **Copy path** | Copies where the file is, for pasting elsewhere. |
| **Move to Trash…** | Deletes the project file (not your video files). You'll be asked first. |

Your video files never move or change when you do any of this.
