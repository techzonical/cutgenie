# Collect media in one folder

**Collect media** copies every video, sound and picture the project uses into one folder, then points the project at
the copies. Your originals stay where they are.

Use it before you back up a finished video or move it to another Mac.

1. Click the project name above the viewer and choose **Collect media…**.
2. Cutgenie tells you how many files and how much space they need.
3. Choose (or make) a folder and confirm.

Keep the project file in the same folder, and the whole edit is in one place.
