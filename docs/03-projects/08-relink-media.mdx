# Relink missing media

If you move or rename your video files, the project can no longer find them. Missing clips show as **media missing**.

1. Click the project name above the viewer and choose **Relink missing media…**.
2. Choose the folder the files are in now. Sub-folders are searched too.
3. Cutgenie matches the files by name and tells you how many it found.

If some are still missing, run it again on another folder.

> Moving a whole folder (project file and recordings together) usually keeps everything linked.
