# Open, switch and close projects

- **Open a project**: **File ▸ Open…** (**⌘O**), then pick a `.cutgenie.json` file.
- **Tabs**: every open project gets a tab just above the timeline. Click a tab to switch. Your place in each project
  is kept.
- **Close a tab**: click the small **×** on it. The project file is kept; only the tab closes.
- **Close project**: click the project name above the viewer and choose **Close project**.

When you open Cutgenie, it brings back the project you were last working on.
